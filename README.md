## 🛠️ Track 1: [DN5-Upskilling](file:///c:/Users/dashi/OneDrive/Desktop/3-2/Cognizent/Cognizant-DN5/DN5-Upskilling) (Foundations)

*📖 Detailed Documentation: [DN5-Upskilling README](file:///c:/Users/dashi/OneDrive/Desktop/3-2/Cognizent/Cognizant-DN5/DN5-Upskilling/README.md)*

### 🌐 Module 1: Web Development Technologies (60 Exercises)
* **HTML5 (10 Ex)**: Semantic layout (`<header>`, `<main>`, `<article>`), accessible forms, media elements, tables.
* **CSS3 (11 Ex)**: Flexbox layouts, CSS Grid, media queries, keyframe animations, glassmorphism, custom properties.
* **Bootstrap 5 (19 Ex)**: Responsive grid, dynamic modals, carousels, cards, navbars, utility classes.
* **JavaScript ES6+ (14 Ex)**: DOM manipulation, asynchronous programming (`fetch`, `Promise`, `async/await`), closures, event loops.
* **jQuery (6 Ex)**: DOM traversal, animations, AJAX HTTP requests, UI interactions.

### 🗄️ Module 2: ANSI SQL Using MySQL (25 Queries)
* **Database**: `community_portal_db` (8 Relational Tables: `Users`, `Events`, `Speakers`, `Sessions`, `Registrations`, `Feedback`, `Organizers`, `Resources`).
* **Key Topics**: Multi-table inner/outer/self joins, window ranking functions (`DENSE_RANK`), conditional aggregation (`CASE WHEN`), date-time manipulation, subqueries, anomaly detection.

### ⚙️ Module 3: C# 12 & ADO.NET (30 Exercises)
* **Core C#**: Type safety, stack vs heap, C# 12 primary constructors, pattern matching, constructor chaining.
* **Collections & LINQ**: Generic collections, lambda queries, filtering, grouping, projections.
* **Async & Concurrency**: Multi-threading, task-based async (`async`/`await`), thread synchronization (`lock`, `Monitor.TryEnter`).
* **Database Connectivity**: Enterprise ADO.NET CRUD architecture (`SqlConnection`, `SqlCommand`, `SqlDataReader`, `SqlDataAdapter`, `DataSet`).

## ⚡ Quick Start & Execution Guide

### 1. Prerequisites Setup
Ensure the following tools and runtimes are installed on your machine:
* **.NET SDK**: `dotnet --version` (v8.0 or v10.0+)
* **Node.js & npm**: `node -v` (v20+) and `npm -v`
* **MySQL Server**: `mysql --version` (v8.0+)
* **Angular CLI**: `ng version` (optional, npm scripts included)

---

### 2. Running C# .NET Projects
```powershell
# Restore and run any C# exercise or API project
dotnet restore "DN5-DeepSkilling/Week - 2/ASP.NET-Core-WebAPI/01-CRUD-RestApi/01-CRUD-RestApi.csproj"
dotnet run --project "DN5-DeepSkilling/Week - 2/ASP.NET-Core-WebAPI/01-CRUD-RestApi/01-CRUD-RestApi.csproj"

# Run NUnit automated test suites
dotnet test "DN5-DeepSkilling/Week - 1/NUnit-Moq/NUnit-HandsOn"
```

---

### 3. Running the Angular SPA (Student Course Portal)
```powershell
# Step 1: Navigate to the application
cd "DN5-DeepSkilling/Week - 5/Angular_HandsOn/Student-course-portal"

# Step 2: Install dependencies
npm install

# Step 3 (Terminal 1): Launch mock REST API on http://localhost:3000
npm run api

# Step 4 (Terminal 2): Launch Angular dev server on http://localhost:4200
npm start
```

---

### 4. Running MySQL Database Scripts
```powershell
# Execute SQL setup and sample queries against MySQL
mysql -u root -p < "DN5-Upskilling/Module 2/ANSI SQL Using MySQL/Hands-on Exercise/schema_and_data.sql"
mysql -u root -p < "DN5-Upskilling/Module 2/ANSI SQL Using MySQL/Hands-on Exercise/all_exercises_solution.sql"
```
