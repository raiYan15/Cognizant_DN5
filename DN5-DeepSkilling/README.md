## ⚡ Quick Start & Execution Guide

### 1. Running ASP.NET Core Web API Projects
```powershell
# Navigate to any Web API project (e.g., Week 2 CRUD Rest API)
cd "Week - 2/ASP.NET-Core-WebAPI/01-CRUD-RestApi"

# Restore dependencies and launch API
dotnet restore
dotnet run
```
*Access the Swagger UI at `https://localhost:<port>/swagger` in your browser.*

---

### 2. Running Entity Framework Core Projects
```powershell
# Navigate to an EF Core project
cd "Week - 2/Entity-Framework-Core/01-CodeFirst-Relationships"

# Apply migrations and update database
dotnet ef migrations add InitialCreate
dotnet ef database update

# Run the console demonstration
dotnet run
```

---

### 3. Running the Angular Student Course Portal (Week 5)
```powershell
# Navigate to the Angular application
cd "Week - 5/Angular_HandsOn/Student-course-portal"

# Install dependencies
npm install

# Terminal 1: Launch mock REST backend (port 3000)
npm run api

# Terminal 2: Launch Angular development server (port 4200)
npm start
```
*Open [http://localhost:4200](http://localhost:4200) to interact with the application.*

---

### 4. Running Unit Tests (NUnit / Jasmine)
```powershell
# Run .NET NUnit tests
dotnet test "Week - 1/NUnit-Moq/NUnit-HandsOn"

# Run Angular unit tests with Karma
cd "Week - 5/Angular_HandsOn/Student-course-portal"
npm test
```
