# Week - 7: DevOps, Docker, and GenAI Fundamentals

Week 7 is a notes-focused week covering modern delivery practices,
containerization, orchestration, and Generative AI fundamentals.

## Folder Contents

| Folder | What it contains |
| --- | --- |
| `DevOps/` | Complete DevOps notes in Markdown and PDF form. |
| `Docker_/` | Docker module README plus Markdown and PDF notes. |
| `GenAI-Fundamentals/` | Generative AI module README plus Markdown and PDF notes. |

## DevOps Topics

- DevOps introduction and lifecycle stages.
- DevOps compared with waterfall and traditional delivery approaches.
- Version control systems and Git/GitHub basics.
- CI/CD concepts, pipeline components, tools, and best practices.
- Docker, Kubernetes, Terraform, Prometheus, Grafana, and DevSecOps.
- Quick-revision notes for exam or interview preparation.

## Docker Topics

- Docker introduction, features, and architecture.
- Docker images, containers, commands, and run options.
- Dockerfile and Docker Compose basics.
- Docker Engine, storage, networking, and orchestration.
- Kubernetes introduction and core features.

## GenAI Topics

- Generative AI compared with traditional AI.
- Neural network foundations and transformer architecture.
- Large language models and training stages.
- Prompt engineering techniques.
- Retrieval-Augmented Generation, AI agents, and model families.
- Limitations, risks, ethics, real-world use cases, and responsible AI.

## How to Use

1. Start with `DevOps/DevOps_Complete_Notes.md` for the broad delivery and
   operations overview.
2. Use `Docker_/README.md` and `Docker_/Notes/Docker_Notes.md` for
   containerization study.
3. Use `GenAI-Fundamentals/README.md` and
   `GenAI-Fundamentals/Notes/GenAI_Fundamentals_Notes.md` for AI concepts and
   revision.
