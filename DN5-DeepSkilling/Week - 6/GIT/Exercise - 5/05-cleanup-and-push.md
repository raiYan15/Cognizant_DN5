# Git Hand-On 05: Clean Up and Push to Remote

## Objectives

- Learn how to clean up the local Git state.
- Push pending changes back to the remote repository.

## What You Will Learn

- Verify the current branch state.
- Pull the latest remote changes.
- Push local changes to the remote repository.

## Prerequisites

- A repository with local and remote branches.
- The remote repository should already be configured.

## Steps

### 1. Check repository status

```bash
git status
git branch
```

### 2. Pull latest changes from remote

```bash
git pull origin master
```

### 3. Push local changes

```bash
git push origin master
```

### 4. Verify in the remote repository

Open the GitHub or GitLab repository page and confirm that the latest changes are visible.

---

## Summary

You verified the repository state, pulled the latest updates, and pushed your changes to the remote repository.
