## What each folder contains

### `Hand-On (6 - 10)`

This folder contains starter task notes and structure for Week 6 Angular exercises.
Each task subfolder includes a `README.md` describing the task goal and implementation focus.

Use this folder for the Week 6 exercise flow:

- Hands-On 6: service-layer implementation
- Hands-On 7: routing, guards, and lazy loading
- Hands-On 8: HTTP + RxJS + interceptors
- Hands-On 9: NgRx store and effects
- Hands-On 10: component, service, and NgRx testing

## Remaining file and folder details

The `Hand-On (6 - 10)` folder currently holds task-level guides only.
Create actual Angular source files in each task subfolder as you build the exercises.

If you later add a working sample app for Week 6, keep it separate from this task-note structure, and do not rename the existing `Hand-On (6 - 10)` folder.

## Recommended use

- Open `Hand-On (6 - 10)/README.md` first to understand the task sequence.
- Then navigate into each `Hands-On X/Task Y` folder for the exercise-specific instructions.
- Use this folder as the task outline and map it to the actual source files in your Angular project.
