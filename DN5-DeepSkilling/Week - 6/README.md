# Week - 6: Angular Hands-On 6 to 10, CI/CD, and Git

Week 6 continues Angular with service, routing, HTTP, NgRx, and testing
exercises. It also includes DevOps CI/CD notes and Git practicals.

## Folder Contents

| Folder | What it contains |
| --- | --- |
| `Angular/` | Task-level README files for Angular Hands-On 6 through 10. |
| `CI CD/` | DevOps and CI/CD overview with notes on CI, CD, deployment, tools, and lifecycle stages. |
| `GIT/` | Five Git hands-on exercises in Markdown and PDF form. |

## Angular Hands-On Topics

| Hands-On | Tasks |
| --- | --- |
| Hands-On 6 | Course service and enrollment service. |
| Hands-On 7 | Routing, guards, and lazy loading. |
| Hands-On 8 | HTTP CRUD, RxJS, and interceptors. |
| Hands-On 9 | NgRx store and effects. |
| Hands-On 10 | Component testing, service testing, and NgRx testing. |

## CI/CD Topics

- Introduction to DevOps.
- Continuous Integration, Continuous Delivery, and Continuous Deployment.
- Differences between CI and CD.
- Common DevOps tools for version control, pipelines, containers,
  orchestration, configuration management, and monitoring.
- DevOps lifecycle stages.

## Git Exercises

| Exercise | Topic |
| --- | --- |
| `Exercise - 1` | Git setup, first file, commit, and remote connection. |
| `Exercise - 2` | `.gitignore` usage. |
| `Exercise - 3` | Branching and merging. |
| `Exercise - 4` | Merge conflict resolution. |
| `Exercise - 5` | Cleanup, pull, push, and remote verification. |

## How to Use

1. Open `Angular/README.md`, then follow the task folders under
   `Angular/Hand-On (6 - 10)/`.
2. Review `CI CD/README.md` and `CI CD/Hand-On/DevOps_CICD_Notes.md` for the
   DevOps and pipeline theory.
3. Work through the Git exercises in order from `Exercise - 1` to
   `Exercise - 5`.

## Notes

- The Angular folder currently stores task guides rather than a separate
  runnable Week 6 app.
- The Git folders include both `.md` and `.pdf` versions of each exercise.
