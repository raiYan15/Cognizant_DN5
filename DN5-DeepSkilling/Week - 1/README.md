# Week - 1: Advanced SQL & Engineering Concepts

This week covers Advanced SQL topics and core engineering concepts.

Subfolders

- Advanced SQL/ — SQL lab files: AdvancedConcepts.sql, Cursors.sql, ExceptionHandling.sql, Functions.sql, Indexing.sql, StoredProcedures.sql, Triggers.sql, Views.sql.
- Engineering concepts/ — Algorithm and design-pattern exercises (Exercises 01–07 for algorithms/data-structures and design patterns).
- NUnit-Moq/ — Unit testing hands-on with NUnit and Moq. Includes sample projects and tests (Calculator, Moq hands-on examples).

How to use

- Open the SQL files in `Advanced SQL/` for examples and run them against a sample database.
- Follow the `NUnit-Moq/README.md` for unit test instructions and running tests in Visual Studio or dotnet CLI.

Notes

- These materials are primarily read-and-run labs; each folder contains task-level README files where applicable.
