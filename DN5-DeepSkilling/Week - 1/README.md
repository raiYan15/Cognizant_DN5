# Week - 1: SQL, Engineering Concepts, NUnit, and Moq

Week 1 covers database programming, engineering fundamentals, design patterns,
and introductory unit testing. The folder combines SQL scripts, C# algorithm
exercises, Java design-pattern examples, and .NET test projects.

## Folder Contents

| Folder | What it contains |
| --- | --- |
| `Advanced SQL/` | SQL scripts for advanced concepts, cursors, exception handling, functions, indexing, stored procedures, triggers, and views. |
| `Engineering concepts/Algorithms Data Structures/` | C# exercises `Exercise_01` through `Exercise_07` with `.cs` and `.csproj` files. |
| `Engineering concepts/Design Pattern Principles/` | Java examples for common design patterns, including singleton, factory method, builder, adapter, decorator, proxy, observer, strategy, command, MVC, and dependency injection. |
| `NUnit-Moq/` | NUnit and Moq hands-on projects, including calculator unit tests and customer communication tests using mocked mail sending. |

## Learning Focus

- Practice advanced SQL objects and procedural SQL patterns.
- Solve foundational algorithm and data-structure exercises in C#.
- Understand object-oriented design patterns through Java examples.
- Write automated tests with NUnit.
- Use Moq to isolate dependencies during unit testing.

## How to Use

1. Open the scripts in `Advanced SQL/` and run them against a suitable SQL
   database environment.
2. Open the C# exercise folders with the .NET CLI or Visual Studio.
3. Compile and run the Java design-pattern examples from their exercise folders.
4. Use `NUnit-Moq/README.md` as the starting point for the unit-testing hands-on
   projects.

## Notes

- Compiled Java `.class` files are present beside several Java source files.
- The SQL, algorithm, design-pattern, and testing folders are independent
  practice areas, so they can be studied in any order.
