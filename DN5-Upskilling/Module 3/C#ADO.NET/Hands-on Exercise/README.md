Open terminal in the workspace and execute:
```powershell
dotnet run --project "Module 3\C#ADO.NET\Hands-on Exercise\Exercise <N>\Exercise<N>.csproj"
```
*(Replace `<N>` with the desired exercise number 1 through 30)*
