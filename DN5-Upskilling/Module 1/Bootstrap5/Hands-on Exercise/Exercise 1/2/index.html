How to Set Up Bootstrap Locally

Three simple steps — works completely offline after setup.

Step 1
Download Bootstrap

Visit getbootstrap.com and click "Download". You get a .zip containing compiled CSS and JS.

  • 📦 bootstrap.min.css
  • 📦 bootstrap.bundle.min.js
Step 2
Organise Your Folder

Place the downloaded files into css/ and js/ subfolders inside your project directory.

  • 📁 project/css/bootstrap.min.css
  • 📁 project/js/bootstrap.bundle.min.js
Step 3
Link in Your HTML

Use relative paths in your HTML to point to the local files — no CDN URL needed.

  • 🔗 <link href="css/bootstrap.min.css">
  • 🔗 <script src="js/bootstrap.bundle.min.js">

CDN vs Downloaded — Quick Comparison

CDN (Exercise 1.1)
  • 🌐 Requires internet connection
  • ⚡ No files to maintain locally
  • 🔄 Always gets latest cached version
  • 📉 Depends on third-party server uptime
Downloaded (Exercise 1.2)
  • ✅ Works completely offline
  • 🔒 Full control over the version used
  • 🚀 Can be served via your own fast server
  • 🛠️ Customisable with Sass (later exercises)
