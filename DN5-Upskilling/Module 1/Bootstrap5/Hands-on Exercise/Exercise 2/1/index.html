Bootstrap Directory Structure

css/
Contains:
  • bootstrap.min.css
  • bootstrap.rtl.min.css
  • bootstrap-grid.min.css
  • bootstrap-utilities.min.css

Purpose: Provides all core styling, responsive grid systems, flexbox utilities, and component styling.

js/
Contains:
  • bootstrap.bundle.min.js (includes Popper)
  • bootstrap.min.js (requires separate Popper)
  • bootstrap.esm.min.js

Purpose: Enables interactive components such as modals, dropdowns, tooltips, carousels, and collapse toggles.

icons/ / font/
Contains:
  • bootstrap-icons.css
  • fonts/ (woff, woff2)
  • SVGs folder

Purpose: Provides scalable vector icons that can be embedded via CSS classes, SVG sprites, or web fonts.
