## ⚡ Quick Start Guide

### 1. Running C# .NET Exercises (Module 3)
Ensure you have .NET SDK installed:
```powershell
# Verify SDK version
dotnet --version

# Run any exercise (e.g., Exercise 20 LINQ)
dotnet run --project "Module 3\C#ADO.NET\Hands-on Exercise\Exercise 20\Exercise20.csproj"

# Run ADO.NET CRUD operations (Exercise 30)
dotnet run --project "Module 3\C#ADO.NET\Hands-on Exercise\Exercise 30\Exercise30.csproj"
```

### 2. Running MySQL Database Exercises (Module 2)
```powershell
# Set up database and seed sample data
mysql -u root -p < "Module 2/ANSI SQL Using MySQL/Hands-on Exercise/schema_and_data.sql"

# Execute all 25 queries in batch
mysql -u root -p < "Module 2/ANSI SQL Using MySQL/Hands-on Exercise/all_exercises_solution.sql"
```
*Or open `all_exercises_solution.sql` directly inside **MySQL Workbench**.*
